# On the possibility of short-term traffic prediction during disaster with machine learning approaches: An exploratory analysis

## Metadata

Authors: Makoto Chikaraishi, Prateek Garg, Varun Varghese, Kazuki Yoshizoe, Junji Urata, Yasuhiro Shiomi, Ryuki Watanabe <br>
Release Date: 2020/05 <br>
Journal: Elsevier <br>

## What they did
  
+ Exploratory analysis of machine learning algorithms for short term traffic flow prediction
+ Using Data from 2018 heavy rain disaster in hiroshima to train machine learning models
+ Comparison of models based on accuracy and explainability

## Focus

+ exploring possible solutions for short term traffic predictions
+ Predictions are for regular traffic after the disaster (considering relief traffic)
+ Giving recommendations off algorithms to prepare for this scenario

## Findings

+ Deep Learning Models struggle with disaster scenarios due to a lack of data
+ Accuracy should not be the only goal, interpretability is also important
+ random forest and XGBoost explain variance in data really well
  
## What they did not do

+ simulation
+ the time frame during the disaster
+ evacuation traffic
+ transfer learning
